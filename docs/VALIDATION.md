### 未覆盖

独立 Chrome 连接返回 `Codex auth token is unavailable`，未通过该浏览器检查。之前 Windows 计算机操作因无法确认 URL 而停止，本地 `file://` 也受浏览器策略限制，未绕过。手机实机仍未覆盖；窄屏模拟仅能证明相应 Chromium 布局。

不承诺所有 PDF、所有 JPEG 编码器、恶意输入或所有去水印攻击已覆盖。暗标记是实验性功能，不能单独识别传播者。

- 10 项纯函数测试：页码解析、尺寸限制、编号、像素标记、缩放导致失效、Unicode 元信息、CRC、图片型 PDF、密度与覆盖区域。

- 源码语法检查、静态构建与 SHA-256 生成。

## 实际浏览器检查（Chromium 内置浏览器）

- 通过文件选择器导入两张匿名化 PNG，以及两页扫描 PDF。
- 内置两页 PDF 示例、本地含 Helvetica 文字的 PDF：解析、预览和翻页通过。
- 修改用途文字、水印密度、清晰度和最长边；空水印禁用导出，错误页码返回明确提示。
- 实际下载 PNG、JPEG、多页 PDF；下载文件经图像解码器和严格 PDF 读取器检查。PNG/JPEG/PDF 的元信息与隐藏编号可在网页中读回。
- 关闭元信息和隐藏标记后保存 PNG，再验证时两者均未检出；重新启用选项后恢复正常设置。

- 断网后的图片型 PDF 导出成功。网络模拟已恢复，未改变用户的系统网络配置。
