# 验证记录（v0.2.0）

验证日期：2026-10-11 至 2026-10-12（Asia/Singapore）。

## 已通过

- 10 项纯函数测试：页码解析、尺寸限制、编号、像素标记、缩放导致失效、Unicode 元信息、CRC、图片型 PDF、密度与覆盖区域。
- 两张用户指定的文档示例经过 PNG/JPEG 导出，可正常解码，并可读取新增水印元信息。
- 两张示例各自的 JPEG 质量 92、80、60 输出，检出了演示隐藏编号。这是当前样本结果，不代表其他压缩器或攻击后的可靠性。
- PDF.js 5.6.205 在本地解析并绘制两页示例 PDF。
- 严格 PDF 读取器确认两页输出：每页仅一个合成 JPEG，没有文本、字体、批注和原始无水印对象；可读取中文元信息。
- 源码语法检查、静态构建与 SHA-256 生成。

## 实际浏览器检查（Chromium 内置浏览器）

- 通过文件选择器导入两张匿名化 PNG，以及两页扫描 PDF。
- 内置两页 PDF 示例、本地含 Helvetica 文字的 PDF：解析、预览和翻页通过。
- 修改用途文字、水印密度、清晰度和最长边；空水印禁用导出，错误页码返回明确提示。
- 实际下载 PNG、JPEG、多页 PDF；下载文件经图像解码器和严格 PDF 读取器检查。PNG/JPEG/PDF 的元信息与隐藏编号可在网页中读回。
- 断网后解析含文字的 PDF。测试曾发现标准字体 URL 请求被 CSP 阻止，修复为 `useSystemFonts:false`、强制内置资源；复测没有 HTTP 请求，文字正常显示。
- 断网后的图片型 PDF 导出成功。网络模拟已恢复，未改变用户的系统网络配置。
- 390 像素窄屏覆盖检查没有横向溢出；增加了设置/预览快捷跳转、触控按钮尺寸和输入字号。
- 保存实际桌面与窄屏界面图，文档示例只包含公开样本、虚构数据及公开演示编号。

## 未完成的兼容性范围

- 独立 Chrome、Edge 和手机 Safari/Chrome 的实际设备测试。窄屏模拟不等于手机实机。
