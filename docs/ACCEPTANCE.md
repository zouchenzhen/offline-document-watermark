# 验收清单

目标是一个便于分发的 MIT 图片/PDF 水印工具，同时支持公开静态在线页和单 HTML 离线文件。v0.3.0 已完成当前可执行的 Node 与内置 Chromium 验收；独立浏览器、本地URL及手机实机范围仍单列未覆盖。旧 v0.2.0 历史发布不被重写。

|---|---|---|

| 密度、字号、颜色、角度、透明度、覆盖范围 | core/app 回归；真实浏览器调节与半页/错误矩形验证 | 通过当前测试 |
| 已有水印 PDF 直接生成发送版 | 空文字、无新增可见水印；实际PNG与输入像素完全一致，PDF两页仅合成成功 | 通过当前测试 |

## 人工操作时应检查

1. 用内置公开样本先试，不要以真实身份证作为第一次测试材料。
2. 添加水印：确认密度变化、翻页、半页/自定义覆盖和输出质量均可见；文字仍能辨认。
3. 只合成发送版：导入已有水印文件，选择“仅合成”，清空额外文字并关闭不需要的追踪选项；确认输出保留原水印且没有新增文字。
4. 暗标记：导出PNG/JPEG/PDF再导入验证；若压缩后检测失败，工具应停止下载并给出调整建议。
5. 对没有既有像素标记的干净样本关闭追踪选项：输出不应新增本工具的元信息或暗标记。开关不清除原文件已经存在的像素标记；“仅合成”模式应保留已有外观。
6. 断网：公开页面已加载后断网，或使用固定离线HTML；导入字体/CMYK/JPEG2000虚构fixture，确认页面完整。
7. 只把检查过的发送版发给对方，不发送原图、源PDF、工程文件或私人追踪记录。

这些步骤是验收标准，不是“已经通过”的证明。实际执行记录应写进 VALIDATION.md，并区分Node、内置Chromium、独立浏览器和手机实机。
