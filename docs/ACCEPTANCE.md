# 验收清单

目标是一个便于分发的 MIT 图片/PDF 水印工具，同时支持公开静态在线页和单 HTML 离线文件。v0.4.2 已完成新增回归、内置 Chromium 的参数单独修改刷新事件与两种可见状态的实际 PDF 输出检查；旧版本证据仍保持历史范围。

## 人工操作时应检查

1. 用内置公开样本先试，不要以真实身份证作为第一次测试材料。
2. 添加水印：确认密度变化、翻页、半页/自定义覆盖和输出质量均可见；文字仍能辨认。
3. 保留已有水印：导入文件，关闭“添加新的可见水印”，清空补充说明并关闭不需要的追踪选项；点击“保存图片型 PDF”，确认输出保留原水印且没有新增文字。再开启可见水印并保存一次，确认 PDF 同样是图片型；不执行第二次转换。PNG/JPEG 使用同样的开关语义。
4. 暗标记：导出PNG/JPEG/PDF再导入验证；若压缩后检测失败，工具应停止下载并给出调整建议。
5. 对没有既有像素标记的干净样本关闭追踪选项：输出不应新增本工具的元信息或暗标记。开关不清除原文件已经存在的像素标记；关闭新增可见水印应保留已有外观。
6. 断网：公开页面已加载后断网，或使用固定离线HTML；导入字体/CMYK/JPEG2000虚构fixture，确认页面完整。
7. 只把检查过的发送版发给对方，不发送原图、源PDF、工程文件或私人追踪记录。
8. 配置记忆：用虚构文案保存、刷新、恢复历史，再关闭记住并清空；检查本机配置没有文件名、材料或追踪记录。
9. 时间前缀：开启和关闭分别导出 PNG/JPEG/PDF，比较文件名、元信息、像素读取和 JSON 记录；完整编号必须一致，旧样本仍可读。
10. 离开提醒：逐项修改参数、文案、随机编号和页码，以及选择材料/验证文件后，再尝试刷新或离开；文件选择本身不应弹离开确认。记住开启时检查离开前待保存配置写入，但文件仍须重新选择；手机后台关闭不能依赖提醒保住数据。

这些步骤是验收标准，不是“已经通过”的证明。实际执行记录应写进 VALIDATION.md，并区分Node、内置Chromium、独立浏览器和手机实机。

用户报告部分样本翻转、裁剪、降低清晰度后仍读到之前信息；未说明信息来自元信息还是像素，也未提供统一处理参数，不能据此把相应攻击测试标为已通过。
